# Rick and Morty Explorer

A modern web application that allows users to explore the Rick and Morty universe, featuring characters, locations, and episodes from the show.

## Features

- **Character Exploration**

  - Browse all characters with pagination
  - Search characters by name
  - View detailed character information
  - See character appearances in episodes

- **Location Discovery**

  - Explore different locations across dimensions
  - Search locations by name
  - View location details and residents
  - Navigate to character profiles from location residents

- **Episode Guide**
  - Browse all episodes
  - View episode details
  - See characters featured in each episode

## Technologies Used

- React 18
- React Router v6
- Framer Motion for animations
- CSS3 with modern features
- Rick and Morty API

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/rickandmorthy.git
   cd rickandmorthy
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:

   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.
